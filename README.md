# International Research Scholars Community (IRSC)

A modern, responsive marketing website for the International Research Scholars Community — built with React + Vite.

## Pages

- **Home** — Hero, mission stats, featured scholars, latest research, publications, opportunities, events, newsletter signup and CTA
- **About** — Mission, values, timeline and leadership
- **Research** — Explore research projects with domain filtering
- **Scholars** — Community scholar directory
- **Publications** — Journals and papers published by members
- **Opportunities** — Grants, fellowships and calls for papers
- **Events** — Conferences, webinars and workshops
- **Contact** — Contact form and community information

## Tech Stack

- React 18 + React Router 6
- Vite 5
- Hand-crafted CSS design system (`src/styles/globals.css`, `animations.css`)

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
